Set up in one pass.

~5 minutes
01

Install Node.js and Claude Desktop

Node.js v18+ (LTS) and the Claude Desktop app. Both free, both quick installs.

02

Clone the repo and run the setup wizard

Handles package installs, downloads the browser, authenticates with Tijori, and writes the Claude Desktop config for you.

$ git clone https://github.com/rj250792/tijori-finance-mcp.git
$ cd tijori-finance-mcp
$ node setup.js
03

Log in through the browser window that opens

A real Tijori Finance sign-in — free accounts work with data limits, Pro is recommended for full access. The session is saved locally so this happens once.

04

Fully quit and reopen Claude Desktop

Not just close the window — quit it, then relaunch. That's what loads the server. Then try: "Search Tata Steel using Tijori MCP".
